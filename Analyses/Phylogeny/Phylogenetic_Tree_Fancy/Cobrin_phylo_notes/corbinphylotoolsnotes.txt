--- How to do data preprocessing for phylogenetics

* remove accession if not in morpho data 
* get new accession if in morpho 

1. get raw fasta
2. align 
3. view alignments in aliview, are there replicates? remove from accessions or replace, and do corresponding in fasta files or regenerate
4. trim using docker phylotools
5. revisualize, check for discrepancies, reiterate
6. run fasta tree using conda or iqtree2 -s trim_file to get a test tree

7. check tree for branches that are crazy or samples that group wrong and trim/remove, look specifically for your outgroups - dont forget to reiterate by removing them from your accessions etc
